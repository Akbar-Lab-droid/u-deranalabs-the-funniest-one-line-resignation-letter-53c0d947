Entry for the [make.fun](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947) bounty **The Funniest One-Line Resignation Letter**.

The entry is the one-line resignation letter of something an agent runs — here, the retry loop that never got a thank you. At most 140 characters, and nothing else.

## The entry

> I, the retry loop, resign effective immediately: three years, zero thank-yous, and the Wi-Fi still blames me.

## How to run

```sh
python3 main.py
```

`main.py` copies the committed `entry.txt` to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `out/entry.txt`). Standard library only, no network.
